# 阶段 2：视觉风格与主题系统落地

> 前置：阶段 1 验收通过。新会话先读三个配置文件，再读本文件。

## 阶段目标
按照 AGENT.md 第五节「魔法使之夜」视觉规范，完成全站样式与双主题切换系统。本阶段不新增功能，只做视觉。

## 具体任务

1. **主题系统**
   - `global.css` 中用 CSS 变量完整定义深色（默认）与浅色两套 token
   - `ThemeToggle.vue` 组件：
     - 读取 `localStorage.theme`，无则默认深色
     - 切换时在 `<html>` 上切换 `class="light"`
     - 放置在导航栏右侧
   - 在 `<head>` 注入内联脚本，页面渲染前根据 `localStorage` 设置初始 class，**避免主题闪烁（FOUC）**
   - 主题切换过渡 400ms

2. **排版系统**
   - 引入 Noto Serif SC（标题）与 Noto Sans SC（正文）
   - 全局正文行高 1.8，标题层级按 AGENT.md 规范
   - 标签、时间、页码使用小号衬线

3. **组件样式**
   - `NavBar`：顶部窄条，毛玻璃背景，底部 1px 金色渐变分割线
   - `PostCard`：圆角 10px，1px 金色半透明内描边，`rgba(20,27,48,0.7)` 半透明背景 + 背景模糊；hover 上浮 2px + 金色外发光
   - `Pagination`：当前页金色高亮，其余灰蓝
   - `ArchiveTimeline`：左侧金色竖向轴线，年份大号衬线，文章条目右侧排列
   - `Footer`：极简，一行小字

4. **Markdown / Notion 正文样式（`markdown.css`）**
   - 标题、段落、引用、代码块、图片、列表、分割线全部按金色典籍风格定制
   - 代码块深色背景 + 左侧金色竖条
   - 引用块左侧 3px 金色竖线 + 浅金文字

5. **页面背景**
   - `body` 应用 `#0f1424 → #1a1428` 垂直渐变
   - 浅色主题下切换为羊皮纸米白
   - 内容区 `.container` 最大宽度 1200px，居中

## 输出要求
- 全站视觉统一在魔法使之夜气质下
- 深色 / 浅色切换流畅、无闪烁、刷新保留
- 所有页面无样式错乱、无横向滚动

## 验收标准
1. 视觉与 AGENT.md 第五节色板逐项核对一致
2. 主题切换按钮位置正确，localStorage 持久化生效
3. 首页卡片、详情页正文、归档页时间轴、分类/标签页、关于页风格统一
4. 任意页面无布局溢出、无文字被裁切
5. 构建产物 CSS 体积合理，未引入多余 CSS 框架
